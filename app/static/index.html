What an answer looks like

Someone asked

"This should show paid and shipped orders, but I only get the paid ones."

SELECT id, amount
FROM orders
WHERE status = 'paid' OR 'shipped';

DBaba Proven from the query

OR needs the column again. OR 'shipped' doesn't compare anything with status. MySQL turns the word into the number 0 and quietly keeps only the paid orders; PostgreSQL refuses the query.

WHERE status IN ('paid', 'shipped')

Checked on MariaDB and PostgreSQL: the fixed query returns both kinds of order.

How it works
