Self-hosted

Run DBaba on your own server.

Install it next to your database. It connects with a read-only account, scans every night and keeps everything on your machine.

DBaba's own screen on a test PostgreSQL database.

Install

Every way in.

Linux installer

One command on Ubuntu, Debian or AlmaLinux. Tested on clean machines for each.

Docker

One container, its port published on the host's 127.0.0.1 only.

Windows

A PowerShell installer with a smoke test on every change.

cPanel

Runs as a Python app behind the host's HTTPS and password protection.

Command line and API

dbaba status, dbaba report and a local API with keys for scripts.

Desktop app

Open DBaba on your server from your laptop, with the key kept in the system keychain.

Security

Built to sit next to production.

  • Listens on 127.0.0.1 only and refuses unknown host names.
  • Connects with a read-only database account; it tells you if the account can change data.
  • The screen password is stored as a scrypt hash; API keys are stored as SHA-256 only and shown once.
  • Five wrong passwords lock the login for ten minutes.
  • No outside AI service, and nothing about your data leaves the server.
